# 量表锚点：PHQ-9 / GAD-7 / MDQ

> 用途：给 Round 1–3 一个**可比较的量化锚点**，让医生一眼看到严重度与变化趋势。
> 边界：量表是筛查工具，不是诊断；不替代面诊；不用来给用户「贴标签」；不连续反复测（同一量表 2 周内重复没有信息量）。

## 0. 使用规则（先读）

1. **先问愿不愿意**：「有几个标准化问题，1 分钟，能帮你把严重度说清楚，要试试吗？」不愿意就跳过，不劝。
2. **时间窗固定**：PHQ-9 / GAD-7 都是「过去两周」。不要混用「最近一个月」。
3. **一次只读题干，不解释选项含义**；用户问「一半以上天数算几天」，答「一周里超过 7 天的一半，大概 4 天以上」。
4. **不替别人打分**：第三人称场景只教怎么问，不代填。
5. **第 9 题单独处理**：PHQ-9 第 9 题任何非 0 分 → 立即转到 SKILL.md 第 1 节的直接询问与熔断判断。
6. **分数只用于描述**：说「你的分数落在中度区间」，不说「你是中度抑郁」。
7. **趋势 > 单点**：一次 14 分不说明什么，两周后 9 分才说明在好转。

---

## 1. PHQ-9（抑郁，过去两周）

「在过去两周里，以下问题困扰你的频率是多少？」
计分：0 = 完全不会；1 = 好几天；2 = 一半以上的天数；3 = 几乎每天。

| # | 条目 |
|---|---|
| 1 | 做事时提不起劲或没有兴趣 |
| 2 | 感到心情低落、沮丧或绝望 |
| 3 | 入睡困难、睡不安稳，或睡眠过多 |
| 4 | 感觉疲倦或没有活力 |
| 5 | 食欲不振，或吃得太多 |
| 6 | 觉得自己很糟，或觉得自己很失败，或让自己/家人失望 |
| 7 | 对事情专注有困难，例如看报纸或看电视时 |
| 8 | 动作或说话速度慢到别人已经察觉；或正好相反，烦躁、坐立不安、动来动去比平时更多 |
| 9 | 有不如死掉，或用某种方式伤害自己的念头 |

**计分与解释**：

- 总分 0–27。0–4 无/极轻；5–9 轻；10–14 中；15–19 中重；20–27 重。
- 第 9 题 ≥ 1：**停止计分解释，先做安全评估**（有没有计划、有没有准备、有没有近身保护）。
- 第 8 题高分（尤其「坐立不安」）要区分「抑郁性激越」与「药物性静坐不能」——后者与剂量相关、想动、腿里有电流感。
- 单条目 1/2/3 的分布比总分更有用：睡眠、食欲、疲乏三项高，常见于躯体症状为主的表现。

## 2. GAD-7（焦虑，过去两周）

「在过去两周里，以下问题困扰你的频率是多少？」计分同 PHQ-9。

| # | 条目 |
|---|---|
| 1 | 感到紧张、焦虑或急切 |
| 2 | 不能停止或控制担忧 |
| 3 | 对各种各样的事情担忧过多 |
| 4 | 很难放松下来 |
| 5 | 由于不安而无法静坐 |
| 6 | 变得容易烦恼或急躁 |
| 7 | 感到害怕，似乎将有可怕的事情发生 |

**计分**：0–21。5–9 轻；10–14 中；15–21 重。

**注意**：

- 第 5 题「无法静坐」与静坐不能、咖啡因过量、甲亢、贫血都会重叠，不要单凭它下结论。
- GAD-7 高 + PHQ-9 也高，很常见；不要因此就认定「两个病」，先看睡眠、咖啡因、药物激活效应。

## 3. MDQ（双相谱系筛查，终生）

「你有没有过这样一段时间——不是服药或饮酒之后——持续至少几天，并且和平时明显不同？」

| # | 条目（是/否） |
|---|---|
| 1 | 感觉非常好或异常兴奋，别人觉得你和平常不一样，或因此惹上麻烦 |
| 2 | 异常烦躁，以至于对人吼叫、争吵或打架 |
| 3 | 自信心大增，觉得自己无所不能，或比平时强很多 |
| 4 | 睡眠比平时少很多，但仍觉得精力充沛 |
| 5 | 说话比平时多，或语速更快 |
| 6 | 思绪飞快，脑子里的想法停不下来 |
| 7 | 很容易被周围的事打断，注意力频繁转移 |
| 8 | 比平时有更多精力 |
| 9 | 比平时更活跃，或做了更多事 |
| 10 | 比平时更善于社交、更外向，例如半夜给朋友打电话 |
| 11 | 对性的兴趣比平时明显增加 |
| 12 | 做了一些不像自己风格、或可能带来麻烦/风险的事 |
| 13 | 花钱多到给自己或家人带来麻烦 |

**判定**：13 题中 ≥ 7 个「是」，且这些情况**曾同时发生**，且造成**中度或严重**的功能问题 → 筛查阳性。

**注意**：

- 阳性 ≠ 双相。睡眠剥夺、甲状腺功能异常、激素变化、兴奋剂/激素类药物、经期相关情绪波动都可模拟。
- 阴性也不排除：很多人记不清轻躁狂期，建议同时问「有没有一段时间睡得少反而更精神」。
- 若阳性，Round 4/5 必须问清是否在抗抑郁药后出现「更烦躁、周期更快、睡眠更少」，这是给医生的关键线索。

## 4. 结果怎么呈现给用户

用一句话 + 一个区间，不贴标签：

> PHQ-9 你打了 14 分，落在「中度」区间；GAD-7 是 11 分，也在中度。这两个分数主要是给医生一个基线，两周后再测一次，能看出是在好转还是原地打转。

不做的：

- 不说「你得了中度抑郁症」。
- 不把分数写进 HTML 报告的标题或结论位；放在「附：量表记录」里，标日期。
- 不用分数劝人吃药，也不用分数否定别人的痛苦（「你才 8 分，不算严重」是错的）。
