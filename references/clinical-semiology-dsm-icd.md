# 精神科临床症状学（Semiology）与病理化术语转译词典

本知识库用于将患者的日常口语化主诉精准映射为 DSM-5 / ICD-11 及精神科病历标准术语，并提供**“通俗一句话理解”**与**“门诊怎么跟医生开口”**示范话术，消除医患之间的信息差。

## 一、口语化主诉 -> 临床病理化术语 -> 门诊开口话术对照表

### 1. 情感与心境维度（Affect & Mood）

| 患者常见口语化描述 | 临床病理化名称（中/英） | 通俗一句话解释（自己理解） | 门诊高效开口话术（对医生说） |
| :--- | :--- | :--- | :--- |
| “以前很喜欢打游戏/追剧/吃美食，现在一点感觉都没有，中奖了也开心不起来” | **快感缺失（Anhedonia）** | 大脑的“快乐奖赏雷达”暂时静音了，分为**期待性快感缺失**（提前想起来就觉得没意思、不想动）和**体验性快感缺失**（真去做了也品尝不到快乐）。 | “医生，我最近有明显的**快感缺失**，不仅不想出门做以前喜欢的事，真去做了也完全体会不到愉悦感，持续大约 X 周了。” |
| “也不算特别难过想哭，就是觉得心里空落落的，对什么都麻木、无所谓，像隔了一层毛玻璃看世界” | **情感淡漠（Apathy） / 情感钝化（Emotional Blunting）** | 像给情绪调了“低饱和度滤镜”，不悲也不喜（需让医生区分是抑郁本身的阴性症状，还是长期吃 SSRI 后血清素偏高抑制了前额叶多巴胺引起的药物性钝化）。 | “医生，我现在悲伤想哭减少了，但出现了明显的**情感钝化/麻木感**，对好事坏事都没反应，想请您评估是残留症状还是药物引起的。” |
| “每天早上醒来的时候最绝望、最难受，到了下午和晚上反而能稍微缓过来一点” | **心境昼夜节律变化 - 晨重夜轻（Diurnal Mood Variation）** | 身体的生物钟与清晨皮质醇激素节律错位了，导致上午像陷在泥潭里，傍晚才稍微退潮（典型生物学抑郁特征）。 | “我的情绪有很典型的**晨重夜轻**节律，每天早上刚醒时最绝望难受，下午四五点以后会稍微减轻。” |
| “觉得自己是个彻底的累赘，哪怕别人安慰我，我也觉得自己犯了不可饶恕的错，连累了所有人” | **无价值感与病理性内疚（Worthlessness & Excessive Guilt）** | 生病的大脑自动戴上了“自我定罪放大镜”，把正常的小失误放大成不可饶恕的罪过。 | “我最近有强烈的**无价值感和病理性自责**，总觉得自己是家人的累赘，道理都懂但控制不住往自己身上揽错。” |
| “一点小事就像点火药桶一样想发火、摔东西，控制不住脾气，事后又很懊悔” | **易激惹（Irritability） / 情绪失控** | 情绪的“缓冲气囊”变薄了，稍微一点外部摩擦就会直接触发防御性暴怒（常见于焦虑、青少年抑郁或双相混合状态）。 | “我最近**易激惹**非常明显，耐受度极低，一点小事就会突发暴躁想发火，发完火又陷入自责。” |

### 2. 思维、认知与执行功能维度（Thought, Cognition & Executive Function）

| 患者常见口语化描述 | 临床病理化名称（中/英） | 通俗一句话解释（自己理解） | 门诊高效开口话术（对医生说） |
| :--- | :--- | :--- | :--- |
| “脑子像坏掉的复读机，一直反复回想过去说错的一句话或糟糕的事，怎么劝自己停都停不下来” | **思维反刍（Rumination）** | 大脑卡在了“消极复盘死循环”里，越想靠思考找出答案，反而陷得越深。 | “我每天躺下或独处时有严重的**思维反刍**，会不受控制地反复回想过去的负面细节，每次持续一两个小时停不下来。” |
| “脑子里总突然冒出一些很可怕、很荒谬的念头（比如怕自己失控伤人、怕没锁门、怕染病），我知道不合理，但越压制越害怕” | **强迫观念 / 侵入性思维（Obsessions / Intrusive Thoughts）** | 大脑的“垃圾邮件拦截器”太敏感了，把每个人偶尔都会闪过的荒唐念头当成真警报死死揪住。**因为你本心极其善良守规矩（自我不协调），所以才会被这些念头吓坏**。 | “我频繁出现**自我不协调的侵入性/强迫思维**，明明知道这些念头毫无道理、我也绝不会去做，但它们反复闯入脑海引起强烈焦虑。” |
| “脑子像灌了铅、生了锈一样，别人问我一句话我要反应好几秒，看书一行字读十遍都进不去脑子” | **思维迟缓（Bradyphrenia）与认知功能减退（脑雾）** | 大脑的 CPU 降频运行了，信息加工速度和工作记忆（临时内存）暂时缩水，不是变傻或痴呆，情绪恢复后会随之可逆恢复。 | “我近期**思维迟缓和注意力、工作记忆减退**很明显，听人说话反应慢半拍，看文档无法提取信息，严重影响工作。” |
| “明明知道有件事很急，心里急得要命，但就是没法拆解步骤开始干；或者对时间完全没概念” | **执行功能障碍（Executive Dysfunction）与启动困难** | 大脑负责“排优先级、踩油门启动”的前额叶指挥官罢工了，不是因为你懒，而是从“想”到“动”的神经传动轴卡住了。 | “我有明显的**执行功能障碍和任务启动困难**，并不是故意拖延，而是面对多步骤任务时大脑完全无法组织和启动。” |
| “觉得脑子转得飞快，一个想法接一个想法往外蹦，嘴巴说话的速度都跟不上脑子转的速度” | **思维奔逸（Flight of Ideas） / 主观思维加速（Racing Thoughts）** | 大脑的油门踩到底了，联想速度过快（需结合睡眠情况排查是否有轻躁狂或混合状态倾向）。 | “我这几天感觉**思维加速/思维奔逸**，脑子里点子一个接一个蹦出来，说话语速变快，很难安静下来。” |
| “总觉得周围人咳嗽、发朋友圈都是在暗中针对我、议论我” | **关系观念（Ideas of Reference） / 被害观念** | 大脑的“威胁警报器”过度敏感，把周围原本随机无关的动静自动连线到了自己身上。 | “我最近变得高度敏感，出现了一些**关系观念**，总怀疑周围人的眼神或言行是在议论我，虽然理智上有时觉得不一定，但还是非常不安。” |

### 3. 意志与精神运动维度（Volition & Psychomotor）

| 患者常见口语化描述 | 临床病理化名称（中/英） | 通俗一句话解释（自己理解） | 门诊高效开口话术（对医生说） |
| :--- | :--- | :--- | :--- |
| “躺在床上想刷牙洗脸或者拿个外卖，心里知道该去，但身体就像被钉在床上一样，完全没力气动” | **意志减退（Avolition） / 动力匮乏** | 大脑的“日常行为电池”电量掉到了 1%，连维持基本洗漱和进食都需要耗费巨大意志力。 | “我有严重的**意志减退**，连下床洗漱、拿外卖这些基本日常活动都很难启动。” |
| “走路、说话、抬手都像慢动作回放，面部也没什么表情” | **精神运动性迟滞（Psychomotor Retardation）** | 心理上的低落已经外显到了身体的动作和语速上，旁人都能看出动作变慢。 | “家里人反馈我最近说话声音变小、语速和走路动作都明显变慢，出现了**精神运动性迟滞**。” |
| “吃了药（或加量）之后，两条腿里面像有蚂蚁爬或者通了电一样难受，根本没法安稳坐着，必须不停抖腿或站起来走动才舒服一点” | **静坐不能（Akathisia）** | **极其重要的药物反应鉴别**：这不是焦虑症发作，而是药物影响了管运动平衡的多巴胺通道，让双腿肌肉收到了错误的“快动起来”信号，医生加一点对症小药（如普萘洛尔）或微调剂量就能解决。 | “医生，我吃这个药/加量后出现了很典型的**静坐不能**，主要是两条腿内部酸胀烦躁、完全没法安稳坐着，必须来回走动才好受一点。” |

### 4. 知觉、睡眠、躯体与创伤解离维度（Perception, Sleep, Somatic & Dissociation）

| 患者常见口语化描述 | 临床病理化名称（中/英） | 通俗一句话解释（自己理解） | 门诊高效开口话术（对医生说） |
| :--- | :--- | :--- | :--- |
| “突然毫无预兆地心跳飙到一百多、胸闷喘不上气、手脚发麻发抖，感觉自己马上就要心梗死掉或者发疯了，去急诊查心电图又说正常” | **惊恐发作（Panic Attack）伴濒死感 / 失控感** | 大脑误拉了“遇到猛兽”的最高级别交感神经警报，肾上腺素瞬间爆发。虽然体验极其恐怖，但**心脏并没有真坏，也不会死人**，通常 10-20 分钟肾上腺素耗尽就会自动平息。 | “我近期发生了 X 次典型的**惊恐发作**，突发心悸、呼吸困难、手脚发麻和强烈的**濒死感**，每次大约持续 20 分钟，现在很怕它再次发作（**预期性焦虑**）。” |
| “感觉自己的灵魂飘在身体外面看自己演戏，或者照镜子觉得镜子里的人特别陌生，看周围的街道像假布景一样不真实” | **人格解体（Depersonalization）与现实感丧失（Derealization）** | 大脑在承受过度焦虑、惊恐或睡眠剥夺时，自动拉下了“情感保险丝（解离保护机制）”，把你和痛苦的感受隔开一层膜。**你没有疯，也不会变成精神分裂**。 | “我在极度焦虑或疲惫时会出现**人格解体和现实感丧失**，感觉看周围世界像隔着一层纱、不真实，看自己也很陌生。” |
| “半夜三四点就突然醒来，醒了之后脑子特别清醒或绝望，再也睡不着，睁眼熬到天亮” | **终末期失眠 / 早醒（Terminal Insomnia / Early Morning Awakening）** | 比平时起床时间提前 2 小时以上醒来且无法再次入睡，是抑郁状态非常典型的睡眠结构改变。 | “我主要的睡眠问题是**终末期失眠（早醒）**，每晚 X 点入睡，但凌晨三四点就会醒来且无法再入睡，总睡眠只有 X 小时。” |
| “这几天每天只睡三四个小时，但白天居然一点都不困，反而精力充沛、想干好多大事、疯狂买东西” | **睡眠需求减少（Decreased Need for Sleep）伴目标导向活动增多** | **最关键的分水岭**：普通失眠是“想睡睡不着、白天累得要命”；而这是“睡很少却电量爆棚”，必须马上告诉医生排查**轻躁狂/双相谱系**！ | “医生，我这几天出现了**睡眠需求减少**，每天只睡三四个小时但白天完全不困，反而精力亢进、想法特别多、冲动消费，想请您排查是否有**转相（轻躁狂）**迹象。” |

## 二、常见器质性与实验室混杂因素排查清单（看诊时可主动请教医生）

许多身体指标异常会完美“伪装”成抑郁或焦虑。初诊或症状久治不愈时，建议提醒用户在医院同步核查以下 4 项常规生理指标：

1. **甲状腺功能全套（TSH、FT3、FT4、抗甲状腺抗体）**：
   - **甲减**会让人极度乏力、怕冷、体重增加、反应迟钝、情绪低落（酷似抑郁症）；**甲亢**会让人心慌、手抖、失眠、脾气暴躁（酷似焦虑症或躁狂）。
2. **血常规与血清铁蛋白（Ferritin）**：
   - 很多人血红蛋白还算正常，但体内的“铁仓库（铁蛋白 < 30 ng/mL）”已经空了。大脑合成多巴胺必须用到铁，缺铁不仅会导致脑雾、心悸，还是诱发**不宁腿综合征**和加重药物**静坐不能**的常见隐形推手。
3. **25-羟基维生素 D、维生素 B12 与叶酸**：
   - 长期室内办公或日照不足极易严重缺乏维生素 D；而维生素 B12 和叶酸是大脑制造血清素和去甲肾上腺素的“原料辅酶”，缺乏时会直接拉低情绪基线并导致抗抑郁药起效变慢。
4. **基线肝肾功能、电解质、血糖血脂与心电图（QTc 间期）**：
   - 帮助医生了解你的“肝脏收费站”和肾脏排泄能力，为安全选药留出充足余量。
