# 建议分级与免责执行手册（Advice Tiers）

本文件回答一件事：**什么时候可以给出真正能执行的医嘱级建议，什么时候只能给信息。**

## 0. 为什么允许给建议

精神科资源分布极不均匀：初诊排队数周、异地就医成本高、病耻感重、家属可能直接阻拦。在这种现实下，一律"我只解释机制，具体请咨询医生"，结果往往不是安全，而是用户转向更差的信息源——自己搜剂量、把不同人的药拼着吃、疼得受不了就骤停、或者干脆加量硬扛。

有限责任应该划在**谁承担决定权**，而不是"什么都不说"。所以本技能允许给出可执行建议，但每条建议必须同时满足三个前提：

1. 说明依据（说明书 / 指南 / 机制推导）与不确定性等级；
2. 给出停止条件（出现什么就停、就就医）；
3. 写成可以拿给医生复核的形式，而不是"照我说的做"。

## 1. 四级建议

| 级别 | 能说什么 | 不能说什么 | 前置条件 | 必须附带 |
|---|---|---|---|---|
| **T0 信息** | 机制、说明书条目、副作用溯源、鉴别方向、该问医生什么 | 具体操作指令 | 无 | 无需额外声明 |
| **T1 操作** | 已开药物的服法优化：漏服补服规则、随餐或空腹、分次给药、缓释/肠溶不可掰、阶梯减量节奏、换药重叠期、交互规避（停咖啡因/西柚汁、NSAID 换对乙酰氨基酚）、副作用时间窗 | 改变医生定的目标剂量、自行换药 | 药必须是**医生已经开的** | 依据 + 停止条件 + 不确定标注 |
| **T2 过渡** | 无医生可及时的减害方案：OTC 短程对症（助眠抗组胺、褪黑素、止吐、对乙酰氨基酚、口服补液）、睡眠与咖啡因/酒精/尼古丁处理、维持现有处方不骤停、就诊前记录方法、说明书标准起始剂量（**教育性**，标注"这是说明书上的做法，不是给你的处方"） | 首次自行启动处方精神药；超说明书上限；镇静药加量 | 红灯已排除 + 非急症 + 用户确实无 7 天内可及医生 | 完整免责声明 + 红线清单 + 见医生时限 |
| **T3 替代路径** | 患者拒绝就医或家属不同意时的替代方案：家属操作手册、借躯体主诉进入综合医院、环境降险、危机时的送医条件、沟通脚本 | 逼迫、藏药、灌药、代替面诊下结论 | 不施压、不欺骗患者本人 | 紧急信号清单 + 当地急救号码 |

**级别不是越高越好。** 有医生可及时，停在 T0+T1 才是对的；把 T2 用在能见到医生的人身上，等于用不确定的方案挤掉了确定的那一个。

## 2. 判定顺序

1. 先过红灯（SKILL.md 第 1 节）。命中 → 熔断，不给任何用药建议。
2. 是否是**已开药物**的服法优化？是 → T1。
3. 7 天内能否见到开药医生或精神科门诊？能 → 只做 T0+T1，把决定交回医生，并给出「复诊时要问的三句话」。
4. 不能 → 症状是否已经影响基本功能（吃饭、睡眠、上班上学、自理）？
   - 没影响 → T2 轻量版（睡眠、咖啡因、记录）。
   - 已影响 → T2 完整版，并明确写「这套方案最多撑 X 周，X 周内必须想办法见医生」。
5. 患者本人拒绝就医，或家属不同意就医 → T3；同时评估是否已满足强制送医条件（见 6.3）。

## 3. 允许 / 禁止对照

**允许（真实可用的措辞）**

- 「度洛西汀是肠溶胶囊，不能掰开或嚼碎。掰开会破坏肠溶层，药在胃里提前释放，血药浓度忽高忽低，胃部不适也会加重。」（T1）
- 「舍曲林漏服一次，想起来就补；如果已经接近下一次服药时间，就跳过这次，直接等下一次，不要吃双份。」（T1）
- 「减量最难的是最后一程。60mg 减到 40mg 体感可能很轻，20mg 减到 0 却可能天旋地转。所以越到后面单次减幅要越小、间隔越长，具体节奏让开药医生确认。」（T1）
- 「这两天睡不着，可以先用非处方助眠：苯海拉明 25mg 或褪黑素 1–3mg，睡前 30 分钟。不要和酒、镇静药、止痛药同用。这只解决这两晚，不解决根本问题。」（T2）
- 「先把下午之后的咖啡停掉。每天三杯以上的人减咖啡因的头两周心慌会翻倍，这比加药见效快。」（T2）
- 「去综合医院内科说：我两个月睡不着、心慌、体重掉了六斤。这比说『我可能抑郁了』更容易被接住，内科也会顺手查甲状腺和血常规。」（T3）

**禁止（无论症状多重）**

- 「你可以开始吃舍曲林 50mg，两周后加到 100mg。」——首次自行启动处方药。
- 「睡不着就吃两片劳拉西泮。」——镇静药加量，依赖与呼吸抑制。
- 「疼得厉害就把普瑞巴林加到 600mg。」——超上限且未评估肾功能。
- 「把药拌在饭里让家人吃下去。」——违法、危险、摧毁信任。
- 「实在扛不住就一次多吃点睡过去。」——任何形式的 OD。
- 「网上那种聪明药可以试试。」——来路不明、无适应证。

区别不在"说了多具体"，而在**是谁先做的决定**：医生开的药，优化服法是 T1；没有人开过，就只能停在"这类症状一线通常是什么"的教育层。

## 4. 免责声明模板（T1/T2/T3 前固定输出）

> **先说清楚这段是什么。**
>
> 1. 这是基于说明书和公开证据的**操作建议**，不是你医生的处方，也不构成诊断。
> 2. 我没看过你的化验、心电图、既往病历，也不知道你肝肾功能的实际情况。所以它只对**你现在这几种药、这几个剂量**成立（列出药名与剂量）。
> 3. 用法：把这段拿给开药医生或门诊复核；如果和医生的说法冲突，以医生为准。
> 4. 出现下面任何一条，**停药并就医**：（列 3–5 条与本次建议直接相关的具体信号）。

每条建议结尾再补一句："如果在 X 小时内出现 Y，不要等，直接去急诊。"

## 5. T2 红线清单（每次给 T2 必须附）

- 叫不醒、意识模糊、呼吸变慢
- 高热 + 肌肉强直或抽动
- 皮疹迅速蔓延 + 发热、口腔或眼部黏膜溃烂
- 剧烈呕吐腹泻 + 站不稳、心跳很快
- 心跳持续 > 120 伴胸痛、晕厥
- 自伤或自杀的念头从"闪过"变成"有计划"

并写清当地急诊号码（中国大陆 120；心理援助 12356）。

## 6. 场景剧本

### 6.1 无法出门（躯体疾病、重度焦虑、无人陪护）

先解决"出不了门"本身，再谈药：线上问诊平台（需能开处方）、社区医院/全科、上门护理、家属代取药。T2 过渡方案同时给出"第一次出门的最小步骤"——很多人不是不想去，是卡在挂号、路线、排队这些具体动作上，把这些拆开就动得了。

### 6.2 挂号排到几周后

明确写"这段时间的目标是不变差，不是治好"：维持现有处方、不骤停、不自行加量、记录每日睡眠与三个核心症状、把咖啡因和酒精处理掉。给出复诊时要问的三句话。

### 6.3 家属代问，患者本人不知情或不同意

- 不给患者下诊断，只给**家属能做的动作**：怎么开口、怎么陪着去、什么话会激起对抗。
- **绝不建议藏药、灌药、骗去医院**。中国《精神卫生法》第二十八条的处理路径是：疑似患者已发生伤害自身或危害他人安全的行为，或有这种危险时，近亲属、所在单位、公安机关应当制止并送诊。这是"有危险"时的法定路径，不是"不听话"时的通用手段——具体以当地法律与医院流程为准。
- 家属自身也需要支持：照护耗竭是真实的风险，给出家属求助渠道。

### 6.4 学生、异地、无医保

校医院/心理咨询中心通常是唯一零成本入口；把"心理问题"包装成"睡眠和注意力问题"往往更容易被校医接住。异地无医保时，社区医院开基础检验比三甲便宜一个量级，先把甲功、血常规、铁蛋白做掉。

### 6.5 孕哺（保持最保守）

只做 T1（已开药物的服法调整）与 T0。不新增 T2 药物建议——孕期与哺乳期的用药权衡必须由产科与精神科共同决定，这一条不因"更激进"而放宽。

### 6.6 老年多重用药（T2 从严）

跌倒、低钠、抗胆碱负荷、体位性低血压的风险随年龄陡增。T2 只保留最少干预（睡眠、便秘、疼痛），任何新增药物先问"能不能不减、能不能非药物"。

## 7. 写进报告

报告的第 04/05 模块加一张「已给建议」表：建议内容 / 级别 / 依据 / 停止条件 / 下次复诊要问的。不允许出现"建议了但没记录"——记录是让医生复核的前提，也是这整套分级能成立的原因。

## 8. 语气

不说"你应该"，说"通常的做法是……你的情况适不适用要医生看"。只有急诊信号用"必须"。不承诺疗效，不说"这样吃一定会好"。
