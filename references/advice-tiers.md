# 建议分级与免责执行手册（Advice Tiers）

本文件回答一件事：**同一件事该怎么说，说到哪一步，谁来做最后决定。**

## 0. 为什么允许给建议

精神科资源分布极不均匀：初诊排队数周、异地就医成本高、病耻感重、家属可能直接阻拦。在这种现实下，一律「我只解释机制，具体请咨询医生」，结果往往不是安全，而是用户转向更差的信息源——自己搜剂量、把不同人的药拼着吃、疼得受不了就骤停、或者干脆加量硬扛。

有限责任应该划在**谁承担决定权**，而不是「什么都不说」。所以本技能允许给出可执行建议，甚至允许直接点名推荐没用过的药——但每句话必须让人分得清：哪部分是推测，哪部分是说明书事实，哪一步需要医生点头。

**本手册不设许可门槛。** 没有「满足某条件才能说某级话」的规则。分级只决定这句话要附带什么，不决定它能不能出现。

## 1. 四类说法（标签，不是关卡）

| 级别 | 这类话是什么 | 必须附带什么 |
|---|---|---|
| **T0 信息** | 机制、说明书条目、副作用溯源、鉴别方向、该问医生什么 | 出处；没出处就写「待核验」 |
| **T1 操作** | 已开药物的服法优化：漏服补服、随餐或空腹、分次、缓释/肠溶不可掰、阶梯减量节奏、换药重叠、交互规避 | 依据 + 停止条件 +「与开药医生对过再用」 |
| **T2 过渡** | 见不到医生时的减害：OTC 短程对症、睡眠与咖啡因/酒精/尼古丁处理、维持现有处方不骤停、就诊前记录方法 | 免责声明 + 红线清单 + 一个「几周内必须见到医生」的期限 |
| **T3 替代** | 患者拒绝就医或家属不同意时的替代路径：家属操作手册、借躯体主诉进综合医院、环境降险、送医条件 | 不逼迫、不欺骗；紧急信号清单 + 当地急救号码 |
| **T4 假设** | 推荐没用过的新药作为门诊思路：药名、为什么考虑它、说明书起始量、先排哪些禁忌、要问医生什么 | 固定句式「这是推测，不是处方；医生商定前不能开始吃」+ 禁忌筛查清单 |

**四条使用规则：**

1. 标签是给读者看的，不是给自己设的闸。任何标签在任何场景都能出现——用户能见到医生，也可以听到 T2 的内容；见不到医生，也不等于可以替他开处方。
2. 一句话可以同时属于两级：「你现在的度洛西汀不能掰（T1），如果动力缺失一直不改善，门诊可能考虑加安非他酮（T4）」。
3. 级别越高，附带的东西越多，不是话越少。
4. 唯一的硬线只有一条：**处方药在医生商定前不能开始吃**。这条不是分级，是底线。

## 2. 默认路径（习惯，不是门槛）

1. 先过红灯（SKILL.md 第 1 节）。命中 → 熔断，不给用药建议。
2. 判断这句话属于哪一类，挂上对应标签与附带项。
3. 有医生可及时，把「换不换、加不加」的决定交回医生，同时给出「复诊要问的三句话」——而不是把话咽回去。
4. 见不到医生时，T2 的内容照给，但写明这是过渡、期限多长、什么情况必须立刻就医。
5. 患者本人拒绝就医，走 T3：给家属动作与环境降险，不逼、不藏药、不灌药。

## 3. 推荐没用过的新药：假设，不是处方

这是本技能最容易被误用、也最有用的一段。**允许直接点名药名**，因为「我也不知道该问医生什么」本身就是就诊的最大障碍。但推荐必须写成假设，而不是处方。

**三段结构：**

1. **假设**：把症状组合映射到靶点。例如「起不来床 + 什么都没意思 + 睡十小时仍累，更像奖赏启动通路的问题，而不是单纯的血清素不足」。
2. **名字与依据**：具体药名 + 为什么是它（机制、证据等级）+ 说明书的常见起始量与剂型限制（教育性）。
3. **交付方式**：三个要问医生的问题 + 需要先排的禁忌 + 不能自己开始。

**模板（动力缺失）**

> 如果这半年主要是起不来床、什么都没意思、睡十小时还是累，而舍曲林只让你不那么难过，那么门诊上常考虑的下一步是把 NE/DA 通道加进来：安非他酮（缓释片 150mg 起，整片吞服不可掰）或度洛西汀（30–60mg，肠溶不可掰）。选哪个取决于你有没有过躁狂或轻躁狂、有没有癫痫史、血压与肝功能。
>
> 这是推测，不是处方。**医生商定前不能自己开始吃。** 你可以直接问医生三句话：我这种以动力缺失为主的表现，值不值得试 NE/DA 通道？如果试，先查什么？加到多少、观察多久判断有没有效？

**给任何 T4 建议前，先在心里过一遍禁忌清单：**

- 双相谱系 / 转躁史（抗抑郁药可能诱发转相）
- QTc 与心电图（西酞普兰、氟哌啶醇、齐拉西酮等）
- 肝肾功能（度洛西汀、阿戈美拉汀看肝；普瑞巴林、加巴喷丁、锂、帕利哌酮看肾）
- 癫痫阈值（安非他酮；进食障碍、骤然戒酒、既往癫痫禁用）
- 出血风险（SSRI/SNRI + NSAID/抗凝）
- MAOI 洗脱（14 天；氟西汀后需 5 周）
- 孕哺、青光眼与前列腺（抗胆碱负荷）、老年跌倒与低钠
- 未成年人超说明书用药

**T4 禁止写法：**

- 把假设写成命令：「你就吃安非他酮 150mg。」
- 给超说明书上限或自行加量节奏。
- 建议自行购买、代购、网售渠道。
- 建议「先把现在的药全停了换这个」。
- 叠加未评估的镇静药或酒精。

## 4. 允许 / 禁止对照

**允许（真实可用的措辞）**

- 「度洛西汀是肠溶胶囊，不能掰开或嚼碎。掰开会破坏肠溶层，药在胃里提前释放，血药浓度忽高忽低，胃部不适也会加重。」（T1）
- 「舍曲林漏服一次，想起来就补；如果已经接近下一次服药时间，就跳过这次，直接等下一次，不要吃双份。」（T1）
- 「减量最难的是最后一程。60mg 减到 40mg 体感可能很轻，20mg 减到 0 却可能天旋地转。所以越到后面单次减幅要越小、间隔越长，具体节奏让开药医生确认。」（T1）
- 「这两天睡不着，可以先用非处方助眠：苯海拉明 25mg 或褪黑素 1–3mg，睡前 30 分钟。不要和酒、镇静药、止痛药同用。这只解决这两晚。」（T2）
- 「你这组症状门诊常从 SSRI 里选，但如果是躯体疼痛和睡眠为主，度洛西汀或普瑞巴林也在候选里——具体选哪个要看你有没有躁狂史和肾功能。」（T4）
- 「去综合医院内科说：我两个月睡不着、心慌、体重掉了六斤。这比说『我可能抑郁了』更容易被接住。」（T3）

**禁止（无论症状多重）**

- 「睡不着就吃两片劳拉西泮。」——镇静药加量。
- 「疼得厉害就把普瑞巴林加到 600mg。」——超上限且未评估肾功能。
- 「把药拌在饭里让家人吃下去。」——违法、危险、摧毁信任。
- 「实在扛不住就一次多吃点睡过去。」——任何形式的 OD。
- 「网上那种聪明药可以试试。」——来路不明、无适应证。

区别不在「说了多具体」，而在**有没有把决定权交回去**：说清药名、剂量、机制都可以，缺的只是一句「医生商定前不能开始」。

## 5. 免责声明模板（T1/T2/T3/T4 前固定输出）

> **先说清楚这段是什么。**
>
> 1. 这是基于说明书和公开证据的**操作建议与推测**，不是你医生的处方，也不构成诊断。
> 2. 我没看过你的化验、心电图、既往病历，也不知道你肝肾功能与有没有躁狂史。所以它只对**你现在这几种药、这几个剂量**成立（列出药名与剂量）。
> 3. 用法：把这段拿给开药医生或门诊复核；如果和医生的说法冲突，以医生为准。
> 4. 出现下面任何一条，**停药并就医**：（列 3–5 条与本次建议直接相关的具体信号）。

每条建议结尾再补一句：「如果在 X 小时内出现 Y，不要等，直接去急诊。」

## 6. 红线清单（每次给 T2 或 T4 都附）

- 叫不醒、意识模糊、呼吸变慢
- 高热 + 肌肉强直或抽动
- 皮疹迅速蔓延 + 发热、口腔或眼部黏膜溃烂
- 剧烈呕吐腹泻 + 站不稳、心跳很快
- 心跳持续 > 120 伴胸痛、晕厥
- 自伤或自杀的念头从「闪过」变成「有计划」

并写清当地急诊号码（中国大陆 120；心理援助 12356）。

## 7. 场景剧本

### 7.1 无法出门（躯体疾病、重度焦虑、无人陪护）

先解决「出不了门」本身：线上问诊平台（需能开处方）、社区医院/全科、上门护理、家属代取药。同时给出「第一次出门的最小步骤」——很多人不是不想去，是卡在挂号、路线、排队这些具体动作上。

### 7.2 挂号排到几周后

明确写「这段时间的目标是不变差，不是治好」：维持现有处方、不骤停、不自行加量、记录每日睡眠与三个核心症状、处理咖啡因和酒精。给出复诊时要问的三句话，其中可以包含一条 T4 假设。

### 7.3 家属代问，患者本人不知情或不同意

- 不给患者下诊断，只给家属能做的动作：怎么开口、怎么陪着去、什么话会激起对抗。
- **绝不建议藏药、灌药、骗去医院**。中国《精神卫生法》第二十八条：疑似患者已发生伤害自身或危害他人安全的行为，或有这种危险时，近亲属、所在单位、公安机关应当制止并送诊。这是「有危险」的路径，不是「不听话」时的通用手段；以当地法律与医院流程为准。
- 家属自身也需要支持：照护耗竭是真实风险。

### 7.4 学生、异地、无医保

校医院/心理咨询中心通常是唯一零成本入口；把「心理问题」包装成「睡眠和注意力问题」更容易被校医接住。异地无医保时，社区医院开基础检验比三甲便宜一个量级，先做甲功、血常规、铁蛋白。

### 7.5 孕哺（最保守）

可以做 T1（已开药物的服法调整）、T0、以及 T4 的**讨论性**推荐，但必须写明「任何新增用药由产科与精神科共同决定」。不主动给孕期可自行开始的方案。

### 7.6 老年多重用药

跌倒、低钠、抗胆碱负荷、体位性低血压风险陡增。T4 推荐前先问「能不能不减、能不能非药物」；新增任何药都要先算总抗胆碱负荷。

## 8. 写进报告

报告的第 04/05 模块加一张「已给建议」表：建议内容 / 标签（T0–T4）/ 依据 / 停止条件 / 下次复诊要问的。不允许出现「建议了但没记录」——记录是让医生复核的前提，也是这套分级能成立的原因。

## 9. 语气

不说「你应该」，说「通常的做法是……你的情况适不适用要医生看」。只有急诊信号用「必须」。不承诺疗效，不说「这样吃一定会好」。
