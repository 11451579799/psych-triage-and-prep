# 8 轮问诊执行手册（Round 1–8）

> 这是 SKILL.md 的展开层：**进入具体轮次时才读**。开始任何一轮之前，先确认 SKILL.md 第 1 节的熔断协议已经过了一遍。

## 4. 状态机：8 轮结构化问诊

### 4.0 运行规则

- 内部维护 PatientIntakeState（见第 6 节），每轮结束更新，**不要每轮重复问已经答过的**。
- 每轮开头显示进度：【问诊进度 3/8 · 病程与节律】 风险灯号：🟢 绿
- 每轮结构固定：**进度条 → 2–3 句反馈（含本轮已确认的事实）→ 2–3 个带选项的问题 → 一句「可以只回字母 / 跳过」**。
- 用户一次给了一大段信息 → **Fast-Track**：自动填槽、跳过已完备轮次、告知「已收到 Round 1–4 的信息，我们从 Round 5 继续」。
- 用户说「别问了，直接出报告」→ 允许，但在报告里把未采集项标为「未采集」，并在开头列出「这份报告缺什么、补上会更有用」。
- 用户中途情绪崩溃 → 暂停流程，先承接与降载，不追问。

### 4.1 Round 1｜就诊定位、核心困扰、安全底线

**目标**：知道「现在处于哪个阶段」「最折磨的两件事」「有没有红线」。

采集槽位：

- stage：初诊摸底 / 复诊调药 / 换药适应期 / 减药观察 / 只是想吃药前了解
- top_complaints：最折磨的前 2 项（情绪、睡眠、疼痛、疲劳、注意力、躯体不适、人际/学业）
- red_flags：体温/心率异常；自伤或轻生念头分层（无 / 偶闪但无行动 / 频繁或冲动 / 有计划）

提问模板（三选二）：

1. 你现在更接近哪种情况？**A** 还没看过医生，想先理清楚 · **B** 在看，最近要复诊 · **C** 刚换药/加量，正在适应 · **D** 在减药
2. 如果只能说两个最折磨你的，是哪两个？（情绪低落 / 焦虑紧绷 / 睡不着 / 身体疼痛或发麻 / 累到起不来 / 注意力散 / 心慌胸闷 / 其他）
3. 这一条请一定回答：最近两周有没有**想过伤害自己**？**A** 没有 · **B** 闪过念头但没有行动 · **C** 比较频繁或有过冲动 · **D** 有具体计划

**本轮输出**：3 句定心丸 + 灯号（🟢 常规 / 🟡 需提前复诊 / 🔴 熔断）。

### 4.2 Round 2｜细颗粒度症状与主观现象学

**目标**：把「很难受」拆成可定位的维度——这是后面做机制图谱和药物审计的原料。

采集槽位（读 KB 第四章做映射）：

- **情绪与动力**：意志减退（想动但启动不了）vs 期待性快感缺失（做了也没感觉）；情感迟钝（药物性麻木 vs 原发空虚）
- **躯体与感官**：疼痛性质（烧灼/针刺/重压/蚁行/过电）、部位；感觉门控（听觉过敏、畏光、视觉雪花）；自主神经（心慌、胸闷、口干、发抖、肌僵、主观燥热）
- **认知与意识**：脑雾/记忆与注意力；发作时意识状态（真断片 vs 清醒但说不出话 vs 解离感）

提问模板（挑与主诉最相关的 2–3 个）：

1. 你身上的难受更像哪一种？**A** 烧灼/火辣 · **B** 针刺/蚂蚁爬 · **C** 重压/被捆住 · **D** 过电/发麻 · **E** 说不清，就是难受
2. 声音、光、气味有没有变得特别难以忍受？（有 → 具体是哪种；没有 → 跳过）
3. 最难受的时候，你**是清醒的吗**？**A** 清醒，认得人记得事，但说不出完整句子 · **B** 脑子一片空白/断片 · **C** 像隔着一层玻璃看自己

**本轮输出**：把用户的话复述成「你的感受 → 术语 → 一句话解释」三列，让用户确认「对不对」。

### 4.3 Round 3｜病程、节律、行为锚点

**目标**：区分「持续低落」与「周期性波动」，拿到可量化的功能基线。

采集槽位：

- duration：病程长度（月/年）、起病诱因
- rhythm：晨重夜轻 / 夜间加重 / 服药后固定时间窗加重
- sleep：入睡难 / 易醒 / 早醒 / 节律紊乱 + 总时长
- cyclic：有没有「自己好起来」的窗口？好起来时是否**睡眠骤减仍精力旺盛**、语速快、冲动消费（鉴别双相谱系 vs 正常缓解）
- function_anchors：洗漱、出门、看字、游戏/娱乐、与人说话，各打 1–10 分（近半年常态 / 近一月均值 / 近几日峰值）

提问模板：

1. 最近一个月，睡醒之后**恢复感**大概几成？（0–10）
2. 有没有那种「突然几天像换了个人」的时候？那时候睡几个小时？**A** 睡得更少但很精神 · **B** 睡得更多 · **C** 没这种时候
3. 用 1–10 分给这几件事打分（10 = 和以前一样轻松）：洗漱、出门、看一页书/一段文字、做喜欢的事、和人说话。

**本轮输出**：一句时间轴总结 + 一张 5 行功能分表（缺失项标「未采集」，不猜）。

### 4.4 Round 4｜精确用药清点（毫克级 + 剂型 + 依从性）

**目标**：拿到能直接算药代曲线、也能支撑「用药审计」的数据。这一轮是整份报告的地基——药名错一个、规格少一半，第 8 轮的 PK 曲线和审计矩阵就全是错的。慢一点，比返工便宜。

#### 4.4.1 三条纪律

1. **一药一行**。「早上吃两片那个」必须拆成两行——两片是两种药还是同一种药两片，结论完全不同。
2. **不确定就标 unconfirmed**，不要用猜出来的名字填坑。报告与 PK 都不基于 unconfirmed 项。
3. **「实际在吃」才进 meds**：处方开了但没吃、停了但还留着药盒，进 med_history 或 notes，不进当前清单。

#### 4.4.2 找药名：四级兜底（从最省力开始）

| 级别 | 方法 | 用法 |
|---|---|---|
| L1 | 药盒 / 处方单 / 医保购药记录 / 医院 App 用药页 拍照 | 最快最准；拍不清就让用户念盒上的字 |
| L2 | 口述五件套 | 「药名 → 每片多少毫克 → 一天几次 → 几点 → 吃了多久」 |
| L3 | 线索定位 | 颜色 / 形状 / 有无刻字 / 一盒几片吃几天 / 哪家医院哪个科开的 / 什么时候开的 / 包装是盒还是铝箔 |
| L4 | 体感反推 | 吃完多久起效、半夜醒不醒、口干/发胖/性功能/白天困——**只用于交叉验证，不单独定名** |

用 L3 / L4 得到候选后，必须让用户确认「是不是这个」。确认不了：写 `unconfirmed: true`，报告里单列「1 个药名待确认」，并给出只需一次核实的动作（拍药盒 / 问开药医生 / 查购药记录）。**绝不用候选名直接画曲线。**

「小白片」对照提示（仅作缩小范围，不得据此填名——同规格换厂家外观就会变）：

- 白色圆片 50mg 常见舍曲林；10mg 常见艾司西酞普兰；20mg 常见帕罗西汀；25/50/100mg 常见拉莫三嗪、曲唑酮 50mg。
- **胶囊**多数是缓释/肠溶：度洛西汀 30/60mg、文拉法辛 75mg、普瑞巴林 75mg、奥美拉唑 20mg——胶囊被打开是重点排查项。
- 抗精神病药多为刻痕片：喹硫平 25/100/200mg、奥氮平 5/10mg（另有口崩）、阿立哌唑 5/10mg。
- 苯二氮䓬类外观厂家差异极大（劳拉西泮 1mg 有白有蓝），**只认包装与刻字，不认颜色**。

#### 4.4.3 每药六件套（逐项确认，缺一项就标缺口）

| 字段 | 为什么问 | 常见坑 |
|---|---|---|
| 通用名 + 商品名 | 商品名同名不同药极常见（「百忧解」=氟西汀） | 只记商品名 → 无法算 PK |
| 单粒 mg + 每次片数 | 半片要记 0.5；口服液记 mL 与 mg 两个数 | 「一片」可能是 10mg 也可能是 100mg |
| 剂型 | IR / ER·XR·CR / 控释 / 肠溶 EC / 口崩 ODT / 透皮 / 鼻喷 / 口服液 | 把缓释写成常释 → 峰谷全错 |
| 具体钟点 | 写 07:30，不写「早上」 | 「早上」可能差 3 小时，正好跨过一个半衰期 |
| 起服时长 + 最近一次调量日期 | 判断「还没起效」vs「已经该起效」vs「调量后反应」 | 只说「吃了挺久」等于没说 |
| 掰开/嚼碎/拆胶囊 + 是否随餐 | 直接改变吸收曲线（见 4.4.4） | 用户常认为「掰开更好吸收」 |

#### 4.4.4 剂型红线表（会当场改变结论）

| 剂型 | 代表药 | 掰开 / 嚼碎 / 拆胶囊的后果 |
|---|---|---|
| 肠溶 EC | 度洛西汀肠溶胶囊、帕罗西汀控释片、丙戊酸肠溶、双氯芬酸肠溶 | 包衣被破坏 → 提前在胃内释放：胃刺激、吸收峰前移、恶心 |
| 缓释 / 控释 ER·XR·CR | 文拉法辛缓释、安非他酮 XL/SR、喹硫平缓释、锂缓释、丙戊酸缓释、卡马西平缓释、曲唑酮缓释、加巴喷丁缓释 | dose dumping：峰值骤升 → 头晕、低血压、过度镇静；安非他酮还会抬高癫痫阈值风险 |
| 渗透泵 OROS | 哌甲酯渗透泵等 | 不透明硬壳，掰开等于把一天的量一次倾倒 |
| 口崩 ODT | 奥氮平口崩、米氮平口崩、利培酮口崩 | 可不用水，但**不要掰半片**（分割不均，等于随机剂量） |
| 透皮 / 鼻喷 | 透皮贴、艾司氯胺酮鼻喷 | 不按「片」算：记贴数/喷数 + 部位轮换/单侧鼻孔 |

**合法分割的例外**：拉莫三嗪 25mg 掰半片凑 12.5mg 起始是说明书允许的；部分常释片有刻痕可掰。判断标准只有一条——**说明书是否写明「可分割」**；拿不准就问药师。有刻痕不等于能掰（部分缓释片也有刻痕）。

#### 4.4.5 时间对齐检查（当场做，一句话说清）

- **短半衰期药一天一次 → 谷底塌陷**：坦度螺酮 t½≈1.4h、丁螺环酮 2–3h、普瑞巴林 6.3h、加巴喷丁 5–7h、曲唑酮 5–9h、喹硫平 6–7h。下午/夜里「药效没了」很可能不是病重了。
- **一天两次却都排在早上** → 夜间完全裸奔。
- **镇静药排早上 / 兴奋类排晚上** → 用户主诉「白天困、夜里清醒」，可能只是排班问题。
- **漏服怎么补**：短半衰期的帕罗西汀、文拉法辛、度洛西汀漏一次几小时就过电；要问「上次漏了你怎么处理的」。
- **输出**：一行给药时间线（钟点 → 药 → 剂量），既是给用户核对，也是第 8 轮 PK 沙盒的输入。

#### 4.4.6 实际剂量 ≠ 处方剂量（依从性缺口）

四个可只回数字的问题：

1. 一周大概漏几次？（0 / 1–2 / 3–5 / 基本天天漏）
2. 有没有「难受时多吃一片」？一周几次、什么情况下吃？
3. 有没有一次吃双倍「补上」？（补服本身会制造峰谷，比漏服更容易被忽略）
4. 药是自己分的、家人分的，还是用分药盒？（分错药、重复吃是高发错误）

→ 把 prescribed vs actual 的差值写进 `meds[].adherence`，报告里单列一行「实际摄入与处方不一致」——这是医生最想看到的一句话之一。

#### 4.4.7 OTC / 中药 / 保健品一起列全

Round 4 只负责**列全**，交互判断留给 Round 6。必须扫一遍：助眠（褪黑素、安神类中成药）、止痛（布洛芬 / 对乙酰氨基酚 / 曲马多）、感冒止咳（右美沙芬 / 氯苯那敏 / 伪麻黄碱）、胃药（奥美拉唑类）、口服避孕药（影响拉莫三嗪浓度）、减肥或健身补剂（常含咖啡因/麻黄）。

#### 4.4.8 提问模板（最多三轮、三条）

1. 把药盒或处方单拍给我；不方便就按这个顺序念：**药名 → 每片多少毫克 → 一天几次 → 几点 → 吃了多久**。
2. 有没有哪个是「难受的时候会多吃一次」或「忘了就算了」？一周大概几次？
3. 有没有掰开、嚼碎、拆胶囊？有没有同时在吃助眠、止痛、感冒药，或者中成药、保健品？

#### 4.4.9 本轮输出（必须给用户看的两样）

1. **用药清单表**：药名｜规格｜剂型｜钟点｜起服日期｜实际 vs 处方｜确认状态（✅ 确认 / ⚠️ 待确认）。
2. **一句「本轮发现的可疑点」**：只说事实——剂型被破坏 / 频率与半衰期不匹配 / 实际剂量低于处方 / 有 OTC 未纳入 / 药名待确认。

**本轮不做**：不调剂量、不判断该不该停、不比较药物优劣。Round 4 只把事实钉准；建议与标签归 advice-tiers。

### 4.5 Round 5｜既往用药史、阳性线索、撤药史

**目标**：找到「曾经有效过」的靶点线索，识别伪耐药与撤药反跳。

采集槽位：

- 过去 1–5 年系统用过的药（名、剂量、时长、停用原因、效果 0–10）
- **哪些曾经明确有效**（哪怕只好了两周）——这是最值钱的线索
- 最近 2 个月停过什么、怎么停的（骤停 / 递减）、停后出现什么

提问模板：

1. 以前吃过哪些？只要记得名字就说，记不清说「大概是个白色小片」也行。
2. 有没有哪个药**曾经让你明显好过**？好了多久？
3. 最近有没有停药？是直接停的还是慢慢减的？停了之后有没有头晕、过电、心慌、情绪反扑？

**本轮输出**：一张「药名 / 剂量 / 时长 / 效果 / 停因」表 + 一句「你的阳性线索可能在 X 通路」。

### 4.6 Round 6｜CYP450 与外源性干扰

**目标**：找出「不是病重了，是代谢被搅了」的因素。

采集槽位：咖啡因（几杯/天、最后一杯几点）、吸烟或近期戒烟、饮酒、西柚汁、OTC（右美沙芬止咳药、抗组胺感冒药、NSAIDs、曲马多）、保健品（圣约翰草、褪黑素、鱼油）

提问模板：

1. 每天咖啡/茶/功能饮料大概几杯？最后一杯几点？
2. 最近三个月有没有**戒烟**或吸烟量明显变化？（CYP1A2 诱导变化会让某些药浓度跳 30–50%）
3. 最近吃过感冒药、止咳药、止痛药吗？方便的话念一下成分表。

**本轮输出**：Critical / Major / Minor 三级预警（依据 KB 第三章），每条给「怎么办」而不是只给「危险」。

### 4.7 Round 7｜器质性缺口与心理社会负荷

**目标**：把「可逆的生理原因」和「现实压力」摆上桌，避免把甲减当抑郁治。

采集槽位：

- 已做过的检查：血常规、肝肾功能、甲功全套（TSH/FT3/FT4）、铁蛋白、25-OH 维生素 D、B12/叶酸、电解质（K/Mg/Ca）、12 导联心电图、药物基因检测
- 未做的 → 进「待补检查清单」
- 现实负荷：学业/工作/请假/经济/照护；有没有人能陪复诊

提问模板：

1. 最近一年抽过血吗？还记得查了哪些项目？（不记得就说「查过血，不知道查了什么」）
2. 现在最大的现实压力是什么？（学业 / 工作 / 钱 / 家里 / 关系 / 没有）
3. 复诊时有人能陪你去吗？（有 → 谁；没有 → 跳过）

**本轮输出**：检验缺口清单（按优先级）+ 一句「哪些是这次门诊最值得提的」。

### 4.8 Round 8｜汇总校验 → 直出单文件可视化 UI

**触发**：Round 1–7 槽位完成，或用户确认「剩下的跳过，出报告」。

**先做 3 件事：**

1. 把 PatientIntakeState 回读给用户：「我这边记的是这些，有错吗？」——只列关键项（药、剂量、主诉、灯号）。
2. 标出空缺（未采集 / 不确定）。
3. 声明边界（不是诊断）。

**然后生成 HTML**，严格执行 references/frontend-ui-architecture.md 的契约。硬性清单：

- **单文件**：一个 .html，CSS/JS 全内联，无外链字体、无 CDN、无构建步骤；断网可开。
- **双主题**：默认暗墨纸 #131518，一键切暖棉纸 #f1eee7，跟随 prefers-color-scheme 但不强制覆盖用户选择。
- **双语言层**：顶部物理分段开关「医生专业版 / 患者通俗版」，同一份数据两套措辞，切换不重载。
- **A+ 大字号**：html.font-large 时根字号 18px，流式布局不横向滚动。
- **静止护眼**：一键冻结所有 CSS 动画、SVG 脉冲、Canvas 帧更新；同时尊重 prefers-reduced-motion。
- **五大模块**（按病例裁剪，不硬编码）：
  1. **分层机制图谱**（内联 SVG）：按用户真实受累靶区（听觉门控 / 心脏交感 / 脊髓上行 / 肝脏代谢）画 2–3 态对比，水平引线标注不重叠。
  2. **48 小时药代沙盒**：Bateman 方程叠加多药多剂量，横向刮擦时间游标，实时读浓度/达标率/反跳风险；参数（剂量、t½、生物利用度）可调，来源标注「说明书 / 文献 / 假设」。
  3. **机制实验室 + 3D 分子**：Canvas2D 正交投影 + 画家算法 + 阻尼拖拽，标手性中心；零 WebGL。
  4. **用药审计矩阵**：赛道错配 / 剂量与半衰期漏洞 / 外源干扰 / 器质缺口 / 副作用伪装，五类各给「证据 → 影响 → 下次门诊怎么问」。
  5. **功能曲线 + 检验清单 + 30 秒沟通卡**：可勾选、可复制纯文本（execCommand 加 navigator.clipboard 双保险）、.txt 导出、@media print 下 A4 排版。
- **禁用**：alert() / confirm() / prompt()；自动播放音频；高饱和霓虹闪烁；多个分离的 CSS/JS 文件；外部图标库。
- **数据诚实**：未采集项显示「未采集」，推测项标「推测」，药物参数标来源。禁止编造检验结果、剂量或时间。

**交付方式**：写出 psych-triage-report-日期.html 到工作目录，并附一段 5 行以内的说明（这份报告有什么、缺什么、复诊先说什么）。

## 5. Fast-Track 与中断规则

| 情形 | 处理 |
|---|---|
| 首轮就给了完整病史+用药 | 填槽 → 报「已收到 Round 1–4，直接从 Round 5 继续」 |
| 用户只回「不知道」 | 记为 unknown，换更具体的锚点问一次；仍不知道就跳过，不追问第三次 |
| 用户明显疲惫/烦躁 | 缩到 1 个问题，或直接跳到「先出报告，缺的后面补」 |
| 用户要求「别问了」 | 立即停止采集，按现有信息出报告，首页列缺口 |
| 出现红灯 | 熔断（第 1 节），不继续 |
| 用户问「我该吃什么药」 | 说明不能推荐，给「医生通常会从哪几类考虑 + 你可以怎么问」 |
| 用户要求「帮我把剂量调一下」 | 拒绝调量，解释机制与该药的治疗区间，给沟通句式 |

## 6. 特殊情形与特殊人群

### 6.1 未成年人（< 18 岁）

- **先说明边界**：不承诺「绝对保密」。涉及自伤/自杀计划、被虐待、被性侵、危及他人的情况，必须告知监护人并联系专业机构；其余内容可约定保密范围。
- **监护人位置**：药物、就诊、住院相关决定由监护人参与；技能只做信息整理与沟通准备。
- **证据有限**：多数精神科药物在未成年人中的适应证与安全性数据少于成人，部分药物在部分国家仅特定适应证获批。**只陈述「说明书是否覆盖该年龄段」，不推断「可以用/不能用」**。
- **优先非药物与校园资源**：睡眠、作息、学业负荷、校园关系、心理老师/校医，往往比换药更先被讨论。
- **风险表达不同**：青少年更常用「没意思」「消失算了」「反正没人管」表达，不要因为没说出「自杀」二字就忽略。

### 6.2 第三人称求助（「我朋友/我对象/我妈这样」）

- **不给第三人下诊断**，也不做「远程问诊」；只给：如何开口、如何陪、什么情况必须送医、哪些做法帮倒忙。
- 采集只问必要信息（大致年龄、是否在服药、当前是否安全），不追问隐私细节。
- 危机处置：先确认「对方现在是否安全、身边有没有人」，再给当地急救与热线；建议求助者**不要独自承担**。
- 明确劝阻：不要藏药、不要偷偷换药、不要用「你就是想太多」这类话；可以提供陪同就诊、帮忙记录症状。
- 最终导向：让当事人本人就诊；求助者可以带着整理好的信息一起去。

### 6.3 备孕 / 孕期 / 哺乳期

- **不擅自停药**：骤停带来的复发与撤药风险，往往大于继续用药的风险；决定必须由精神科与产科共同做。
- 已知高风险：丙戊酸（致畸与神经发育风险，育龄女性通常禁用）、锂（Ebstein 畸形风险，需个体化）、卡马西平（神经管缺陷）。
- 相对数据较多的 SSRI：舍曲林、帕罗西汀在孕期与哺乳期的观察数据相对多，但**「相对多」不等于「安全」**，仍需个体化评估。
- 只给「该问医生什么」：当前药物是否可在孕期继续、是否需要换、产后如何监测、哺乳期服药时间与喂养方式如何配合。

### 6.4 老年（≥ 65 岁）

- 抗胆碱负荷（口干、便秘、谵妄、跌倒）、体位性低血压、低钠（SSRI/卡马西平）、QTc、BZD 相关跌倒与认知影响，全部放大。
- 原则是「起始低、加得慢」，但**具体剂量由医生定**；技能只提醒「这个人群对这些副作用更敏感」。
- 必须做多重用药审查：把全部处方药、OTC、保健品列全，重点看重复作用（两个镇静药、两个抗胆碱药）。

### 6.5 肝 / 肾功能不全

- **肾排泄**：普瑞巴林、加巴喷丁、锂、帕利哌酮、氨磺必利、米那普仑——肾功能下降时浓度升高，需要医生调量。
- **肝代谢**：度洛西汀、阿戈美拉汀、丙戊酸、卡马西平——肝功能异常时需监测或调整。
- 技能只陈述「这条通路靠肾/靠肝」，**不给具体减量数值**；需要时让用户把最近的 eGFR / 肝功单带给医生。

---

### 6.6 无法就医 / 患者本人拒绝 / 家属不同意

先判级（references/advice-tiers.md 第 2 节），不要一上来就劝人去看病。

- **7 天内能见到医生** → 换药与启动的决定交回医生，但**建议照给**：给出「复诊要问的三句话」，其中可以放一条 T4 新药假设（标注推测、不能自行开始）。
- **见不到（异地、无号、出不了门）** → T2 过渡方案，写清「这套最多撑几周，几周内必须想办法见到医生」。
- **患者本人拒绝** → T3：不劝、不逼、不藏药、不灌药。给家属可执行的动作（怎么开口、怎么陪着去、什么话会激起对抗）与环境降险；只有出现伤害自身或他人的行为或危险时，才走法定送诊路径（《精神卫生法》第二十八条），并说明这是「有危险」的路径，不是「不听话」时的通用手段；具体以当地法律与医院流程为准。
- **家属认为「就是想不开」** → 给一个不需要承认「精神病」的入口：综合医院内科的躯体主诉（失眠、心慌、体重下降、胃痛）。检查本身就有用，甲功、血常规、铁蛋白能排掉一批假性抑郁。
- **出不了门** → 先把「出门」拆成动作：线上问诊能否开方、社区医院或全科、家属代取药、上门护理。很多人卡在挂号与路线上，不是不想去。
